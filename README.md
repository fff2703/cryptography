# Cryptography

A collection of cryptographic algorithms and cybersecurity-related projects implemented from scratch in Python.

The goal of this repository is to deepen my understanding of modern cryptography, secure programming, and cybersecurity concepts by implementing algorithms without relying on external cryptographic libraries whenever practical.

---

## Repository Goals

- Learn how cryptographic algorithms work internally.
- Improve Python programming skills.
- Practice secure software development.
- Build a portfolio of cybersecurity-related projects.

---

## Projects

### Data Encryption Standard (DES)

A complete implementation of the DES block cipher written from scratch.

**Implemented**

- Initial Permutation (IP)
- Final Permutation (FP)
- Expansion Permutation (E)
- Permutation P
- PC-1 and PC-2
- DES Key Schedule
- Feistel Function
- 16 DES Rounds
- Block Encryption
- Block Decryption
- Binary/Text Conversion
- PKCS#7-style padding (adapted for binary strings)

**Status:** 🚧 In Progress
